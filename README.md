# MoraForesight 4.0 Website

Official event website for MoraForesight 4.0, the fully-funded three-day residential bootcamp for school students under 20, organized by IEEE Student Branch, University of Moratuwa.

## Development

```bash
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```

## Merch Form

Set `NEXT_PUBLIC_MERCH_ORDER_URL` to point merch order buttons to the final order form. Without it, the buttons use the main registration URL.
